# BeatKey

Десктопная ритм-игра, разрабатываемая на C++ с использованием фреймворка Qt 6. 

Игровой процесс построен на синхронизации действий игрока с музыкальной дорожкой: ноты движутся по направляющим к линии регистрации, где необходимо вовремя нажимать соответствующие клавиши. Проект ориентирован на точность таймингов, поддержку пользовательских карт и соревновательную таблицу рекордов.

## Основные возможности

- Игровой процесс с несколькими уровнями точности попадания (Идеально, Хорошо, Сойдет, Промах).
- Подсчет комбо, очков и механика шкалы здоровья (HP).
- Поддержка пользовательских карт в формате .bkey (архив с разметкой map.json, аудиодорожкой и обложкой).
- Встроенный редактор карт для создания и тестирования собственных треков.
- Онлайн-таблица лидеров по каждой карте на базе Firebase Realtime Database.
- Меню настроек с возможностью переназначения клавиш, регулировки громкости и калибровки задержки (аудио-офсет).

## Стек технологий

- Язык: C++17 / C++20
- GUI и модули: Qt 6 (QtCore, QtGui, QtWidgets, QtNetwork, QtMultimedia)
- База данных: Firebase Realtime Database (взаимодействие через REST API)
- Сборка: qmake (поддержка Qt Creator, MinGW / MSVC)
- Целевая платформа: Windows 10 / 11 (x64)

## Требования для сборки

Для сборки и запуска приложения потребуются:

1. Компилятор с поддержкой C++17 или выше (MinGW 11+ или MSVC 2019+).
2. Установленный Qt 6.5 или новее с компонентами:
   - Qt Core
   - Qt Gui
   - Qt Widgets
   - Qt Network
   - Qt Multimedia
3. Qt Creator (рекомендуется) или qmake в командной строке.

## Сборка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/watari1337/BeatKey.git
cd BeatKey
```

### 2. Настройка подключения к базе данных

Перед сборкой скопируйте шаблон конфигурации Firebase в рабочий файл:

```bash
cd BeatKey
cp firebaseconfig.h.example firebaseconfig.h
```

При необходимости укажите URL вашей базы данных Firebase в файле `firebaseconfig.h`. Этот файл добавлен в `.gitignore` и не должен попадать в репозиторий.

### 3. Сборка через Qt Creator

1. Запустите Qt Creator.
2. Откройте проект через меню `Файл -> Открыть файл или проект...` и выберите `BeatKey/BeatKey.pro`.
3. Выберите подходящий комплект сборки (Kit) с Qt 6 (например, Desktop Qt 6.x MinGW 64-bit).
4. Нажмите `Собрать` (Ctrl + B) или `Запустить` (Ctrl + R).

### 4. Сборка из командной строки

В терминале с настроенным окружением Qt:

```bash
cd BeatKey
qmake BeatKey.pro -spec win32-g++ "CONFIG+=release"
mingw32-make
```

Исполняемый файл `BeatKey.exe` будет сформирован в каталоге `release/`.

## Текущий статус разработки

Проект находится в стадии активной разработки:

- Реализовано главное меню, навигация по экранам и диалоговые окна.
- Реализован модуль настроек с чтением и записью конфигурации в INI-файл.
- Разработан клиент для взаимодействия с Firebase Realtime Database (загрузка и отправка рекордов).
- В разработке: игровой цикл, обработка таймингов ввода, парсер карт .bkey, аудио-подсистема и редактор уровней.

## Ветки и правила разработки

Проект использует модель ветвления из трех ключевых веток:

- `main` — стабильные релизные версии проекта. Прямые коммиты запрещены, слияние происходит только после проверки.
- `test` — ветка предрелизного тестирования и проверки стабильности сборок.
- `develop` — основная рабочая ветка текущей разработки. Все новые задачи делаются в отдельных ветках `feature/*` и вливаются в `develop` через Pull Request.
